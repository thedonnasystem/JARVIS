Scoped tokens (Org & Access, M1)

Runs only in this page: no network requests (blocked by the page's security policy), nothing stored. Open this file from your computer, not from a website.

1. Paste the project's JWT secret (Supabase: Project Settings, JWT Keys, legacy JWT secret).

(press Mint)

2. In Railway, Variables: paste the result as FZ_SCOPED_TOKENS, and set FZ_GATEWAY_APIKEY to the project's anon / publishable key (the same value as BACKUP_GATEWAY_APIKEY). Then close this page.

The tokens name an identity only. The database decides what each may do, and the owner can switch any of them off at once (no need to change the secret). Office tokens do nothing until their office is activated. Valid 180 days.
