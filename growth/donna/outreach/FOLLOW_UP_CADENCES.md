# Follow-up cadences

**Rules:**
- Every open tracker row has a `next_action` and `next_action_date`.
- Stop at "no", or at any request to stop, and mark `X`.
- No cold texts: text only people who gave you their number to be texted [S9].

| Situation | Day 0 | Day 1 to 2 | Day 3 to 4 | Day 7 | Day 14 | After |
|---|---|---|---|---|---|---|
| **Audit miss, no conversation yet** (cold) | Call during an owner window, using the audit line | Call at a different window; voicemail ([VOICEMAIL.md](VOICEMAIL.md)) | Walk-in if local, or email A1 if the address is published | Call + email A3 | Email A4 (closing the loop) | Nurture, 60 days |
| **Conversation, review not booked** | Same-day email or DM recap + demo line | Call: "Did you get to call the demo line?" | Book or ask for the one blocker | Call | Last call + email | Nurture, 30 days |
| **Review booked** | Calendar invite + demo line | Reminder the evening before (they gave consent by booking) | | | | |
| **No-show** | Call within 15 min, offer 2 new times | Call | Email | Last call | | Nurture |
| **Review held, no decision** | Recap email: their audit, their calculator estimate (labelled), the offer, the payment link | Call: "What would make it a yes?" | Call: offer the approved risk reversal, if any | Call: founding-spot update (only if true) | Last call | Nurture, 30 days |
| **Warm contact, no reply** | Personal message | | Second message, different angle | Call | | Leave it |
| **Warm contact replied, not a fit** | Ask for 1 introduction to an owner who misses calls | Thank them; follow up the introduction within 24 h | | | | |
| **Partner** | Email or LinkedIn | | Follow-up + one-pager | | Last note | Quarterly check-in |
