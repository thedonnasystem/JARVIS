# Per-vertical hooks (plug into the core scripts)

Every script in this folder has **one core version**. Swap in the short pieces below for the prospect's vertical:
- `[OPENER]`
- `[DEMO_PROMPT]`, for the demo line
- `[PAIN_LINE]`
- `[COST_LINE]`
- `[WHO_ANSWERS]`

**Labels:**
- Values marked "example" are not research.
- Cited figures use [SOURCES.md](../SOURCES.md).

**Before you use a demo prompt:** the demo line is set up on `build/donna-launch`.
- If it is set up for one business type only, use the generic prompt below.
- Or ask for a vertical test line before recording vertical demo clips [OWNER / donna-launch].

## Short-form hooks per vertical (for content, DMs and FB posts)
- **Home services:**
  - "POV: you're on a roof and your phone rings."
  - "No heat at 9 p.m.: voicemail or booked?"
- **Real estate:**
  - "POV: you're mid-showing and a buyer calls about your sign."
  - "Who answers your sign calls on Sunday?"
- **Med spa and beauty:**
  - "POV: you're mid-appointment and the phone won't stop."
  - "The consult that booked somewhere else."
- **Auto:**
  - "Stop scrolling if your techs answer the phone with greasy hands."
- **Law:**
  - "Ever wondered what happens to the 6 p.m. call from a new client?"
- **Clinics:**
  - "Lunch hour: the busiest time for new-patient calls?"
  - Use it only if your own audit data shows it; otherwise ask it as a question.
- **Cleaning and landscaping:**
  - "Spring rush: 10 quote requests, 1 phone, 2 hands."
